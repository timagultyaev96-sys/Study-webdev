# Pixel Web Quest · Веб-квест «Пиксель»

**[English](#english) · [Русский](#русский)**

▶ **Play / Играть:** https://timagultyaev96-sys.github.io/Study-webdev/

## English

A browser game that teaches web development to complete beginners. Marta, a cat wizard, runs a coffee shop called Pixel, and you help her build and bring to life its websites. Every spell is a line of HTML, CSS or JavaScript.

### What's inside

- **110 levels in two seasons.**
  - Season 1, HTML and CSS: tags, lists, links, forms, the box model, flexbox, grid, responsive design, variables, transitions and animations.
  - Season 2, JavaScript: variables, conditions, loops, functions, the DOM and events, objects and array methods, localStorage, timers and your own mini game.
- **Live code editor.** You write real code and see the result right away in a preview. JavaScript levels also have a console.
- **Automatic checks.** Each task comes with a checklist that updates as you type.
- **A helpful owl.** It spots typos in tags, properties and values, and explains JavaScript errors in plain language with line numbers.
- **A growing pixel café.** Every completed level adds an item, plant or piece of furniture to one of 10 rooms. Each room has guests and residents you can talk to.
- **Learning aids.**
  - A world map.
  - Chapter tests, so you can skip a topic you already know.
  - A review book for repeating any lesson.
  - Achievements with pixel-cat portraits.
  - Statistics.
- **Gentle help.** Help comes in three steps (a free nudge, a hint, the solution), and the owl itself delivers its tips. `code` words in a task open a pop-up reminder from the lesson where they were taught.
- **The magic book menu.** One button holds everything extra: repeat any lesson, a cheat sheet with a card for every completed lesson, a free sandbox with no checks (download your page as `index.html`), and the language switch.
- **Two languages.** Switch between Russian and English in the magic book menu. The lessons, the code and the checks all switch.

### Running it

It's one self-contained `index.html` with no build step and no server. Open the file in a browser, or use the GitHub Pages link above. Progress is saved in your browser's localStorage.

On a phone the game has its own layout: a bottom bar switches between the task, the code and the site, and a row of symbol keys (`< > / = " { } ;` and more) sits above the keyboard. From the GitHub Pages link you can add the game to your home screen (Share → Add to Home Screen on iPhone, ⋮ → Install app on Android). It then opens like an app and works offline.

## Русский

Браузерная игра, которая учит веб-разработке с нуля. Кошка-магиня Марта держит кофейню «Пиксель», а ты помогаешь ей собрать и оживить сайты. Каждое заклинание — это строчка HTML, CSS или JavaScript.

### Что внутри

- **110 уровней в двух сезонах.**
  - Сезон 1, HTML и CSS: теги, списки, ссылки, формы, блочная модель, flexbox, grid, адаптив, переменные, переходы и анимации.
  - Сезон 2, JavaScript: переменные, условия, циклы, функции, DOM и события, объекты и методы массивов, localStorage, таймеры и своя мини-игра.
- **Живой редактор кода.** Пишешь настоящий код и сразу видишь результат в превью. На уровнях по JavaScript есть ещё и консоль.
- **Автоматическая проверка.** У каждого задания есть чек-лист, и он обновляется прямо во время набора.
- **Сова-помощница.** Замечает опечатки в тегах, свойствах и значениях, а ошибки JavaScript объясняет простыми словами и с номером строки.
- **Пиксельная кофейня, которая растёт вместе с тобой.** За каждый уровень в одном из 10 помещений появляется предмет, растение или мебель. В помещениях есть гости и жители, с которыми можно поговорить.
- **Помощь в учёбе.**
  - Карта мира.
  - Тесты по главам: знакомую тему можно пропустить.
  - Книга повторения: любой урок можно пройти ещё раз.
  - Достижения с портретами пиксельных котиков.
  - Статистика.
- **Мягкая помощь.** Помощь идёт ступеньками (бесплатный намёк, подсказка, решение), и подсказки даёт сама сова. Слова `кода` в задании открывают напоминание из урока, где их проходили.
- **Меню «Книга мага».** Одна кнопка для всего дополнительного: повторить любой урок, шпаргалка с карточками по пройденным урокам, песочница без проверок (страницу можно скачать как `index.html`) и переключение языка.
- **Два языка.** Русский и английский переключаются в меню «Книга мага». Вместе с языком меняются уроки, код и проверки.

### Как запустить

Вся игра — это один файл `index.html`: без сборки и без сервера. Открой его в браузере или перейди по ссылке на GitHub Pages выше. Прогресс сохраняется в localStorage браузера.

На телефоне у игры своя раскладка: нижняя панель переключает задание, код и сайт, а над клавиатурой появляется ряд символов (`< > / = " { } ;` и другие). С сайта на GitHub Pages игру можно добавить на главный экран (iPhone: «Поделиться» → «На экран „Домой“», Android: ⋮ → «Установить приложение»). Тогда она открывается как приложение и работает без интернета.
